# EA 建模截图操作指南

目标：在 Enterprise Architect 中建立海口旅行网站 UML 模型，并截图提交给老师。

本目录已准备好三份材料：

- `ea-create-haikou-uml.js`：推荐使用，运行后自动在 EA 项目中创建 UML 包、元素和 6 张图。
- `haikou-guide-uml.xmi`：备用导入文件，适合 EA 脚本不可用时导入模型元素。
- `海口旅行网站UML建模报告.md`：每张图的中文说明，截图答辩或报告可参考。

## 一、推荐操作：运行 EA 脚本自动建图

### 1. 打开或新建 EA 项目

1. 打开 Enterprise Architect。
2. 选择 `File` -> `New Project`。
3. 保存为例如：`haikou-guide-uml.qea`。
4. 如果 EA 让你选择模板，选择空白模型即可。

### 2. 打开脚本窗口

不同 EA 版本菜单名字略有差异，常见入口如下：

1. 点击顶部菜单 `Specialize` -> `Tools` -> `Scripting`。
2. 如果没有这个入口，尝试 `Develop` -> `Scripting`。
3. 打开后会看到脚本树，例如 `Local Scripts`。

### 3. 新建 JScript 脚本

1. 在 `Local Scripts` 上右键。
2. 选择 `New Script Group`，命名为 `HaikouGuide`。
3. 在 `HaikouGuide` 上右键，选择 `New JScript`。
4. 脚本名填写：`CreateHaikouUML`。

### 4. 粘贴脚本内容

1. 打开项目文件：`docs/uml/ea-create-haikou-uml.js`。
2. 全选复制文件内容。
3. 粘贴到 EA 的 JScript 编辑窗口。
4. 点击保存。

### 5. 运行脚本

1. 在脚本窗口中右键 `CreateHaikouUML`。
2. 选择 `Run Script`。
3. 等待输出窗口出现类似提示：`完成：请在项目浏览器中打开“海口旅行网站UML模型”下的 6 张图并截图。`
4. 在 EA 左侧 Project Browser 中刷新或展开模型。

运行完成后，应该能看到根包：

```text
海口旅行网站UML模型
  1_用例模型
  2_静态结构模型
  3_交互模型
  4_行为模型
```

里面应包含 6 张图：

```text
01_用例图_系统功能
02_类图_核心领域模型
03_顺序图_用户登录
04_顺序图_发布评论并通知
05_状态图_反馈处理生命周期
06_活动图_地点浏览与互动
```

## 二、截图前的微调

脚本会自动放置元素，但不同 EA 版本可能布局略有差异。截图前建议：

1. 双击打开每张图。
2. 如果元素挤在一起，拖开一点。
3. 如果连接线交叉太多，选中连线后拖动折点调整。
4. 类图内容较多，可以把 EA 窗口最大化再截图。
5. 确保图名、元素名、主要连线都能看清。

不需要把图画得特别花哨，老师主要看 UML 类型、元素、关系和业务是否对应。

## 三、截图方式

推荐方式：

1. 在 EA 中打开某一张图。
2. 点击图空白处，确认当前激活的是图窗口。
3. 使用系统截图工具截图。
4. 文件名按图名保存，例如：

```text
01_用例图_系统功能.png
02_类图_核心领域模型.png
03_顺序图_用户登录.png
04_顺序图_发布评论并通知.png
05_状态图_反馈处理生命周期.png
06_活动图_地点浏览与互动.png
```

如果老师要求截图必须包含 EA 界面，可以保留 EA 顶部工具栏和左侧项目树；如果只要求图，截中间图窗口即可。

## 四、备用操作：导入 XMI

如果 EA 脚本窗口不可用，使用 XMI 备用方案：

1. 打开 EA 项目。
2. 在 Project Browser 中选中一个根包。
3. 点击 `Publish` -> `Model Exchange` -> `Import XMI`。
4. 选择文件：`docs/uml/haikou-guide-uml.xmi`。
5. 导入后检查是否出现“海口旅行网站UML模型”包。

注意：XMI 通常能导入模型元素，但不一定能完整保留图形布局。若导入后没有图，按 `海口旅行网站UML建模报告.md` 中的元素和关系在 EA 中手工新建图。

## 五、如果脚本运行失败

常见处理：

1. 报 `Repository is undefined`：说明脚本不是在 EA 的 Scripting 窗口里运行的，必须在 EA 内运行。
2. 没看到新模型包：右键 Project Browser 空白处或根节点，选择刷新。
3. 图打开为空：关闭图后重新打开，或在 Project Browser 中展开对应包查看元素。
4. EA 版本不支持 JScript：改用 XMI 导入，或按建模报告手工创建。
